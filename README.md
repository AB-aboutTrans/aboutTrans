aboutTrans 是由社群共建的跨性别与多元性别知识平台。我们致力于向公众介绍以跨性别为主、涵盖多元性别议题的知识，帮助更多人了解并支持跨性别与多元性别群体。

项目站点：[aboutrans.info](https://aboutrans.info)。

## 参与共建

参与者可以通过 [电子邮件](mailto:contact@aboutrans.info) 或 [项目交流群](https://qm.qq.com/q/ExEqmGZ16g) 联系我们，也可以在 GitHub 提交 Issue 或 Pull Request，参与共建。
