# 跨性别相关医疗照护

## 性别肯定医疗的基本原则

性别肯定医疗以个人需求、知情同意和持续评估为基础，通常涵盖心理与社会支持、青春期阻滞、激素治疗、手术、嗓音与沟通支持及长期健康管理。不同项目可以单独或组合采用，不存在适用于所有人的固定流程或顺序，其共同目标是缓解性别焦虑、提升自我接纳和心理健康水平；医疗干预也不是跨性别身份成立的前提，心理支持通常贯穿照护全过程。具体方案应在正规医疗机构中，由专业团队与本人共同决定。

## 精神科的诊断

正式接受性别肯定医疗之前，需要进行跨性别身份相关诊断。<mark>这类诊断需由三级甲等医院或精神专科医院的精神科医师作出，但并非所有精神科医师都具备诊断跨性别身份的临床经验</mark>。诊断通常以临床沟通（说明既往及当前状态和就诊诉求）为主，部分医院会辅以量表评估（如 SCL-90、MMPI），有时也涉及激素、染色体等检查。诊断证明的开具要求因地区、医院和医师而异；如医院设置观察期，具体时长和条件应以当地现行要求为准。

> [!NOTE] 根据各地医院应用的诊断标准所包含的诊断名称
>
> * 易性症（ICD-10）
> * 性身份障碍（DSM-IV）
> * 性别不安（DSM-5）
> * 性别不一致（ICD-11）

上述诊断均可作为开展性别肯定激素治疗及性别肯定手术的依据。需要注意的是，虽然跨性别身份的诊断需由精神科医师进行，但<mark>跨性别本身并不是精神障碍</mark>。世界卫生组织在《国际疾病分类》第十一版（ICD-11）中，以“性别不一致”替代了“易性症”等旧诊断分类，并将相关条目从“精神和行为障碍”章节移入“性健康相关情况”章节[^1]。

## 青春期阻滞治疗

青春期阻滞治疗适用于青春期的跨性别青少年，通过促性腺激素释放激素类似物（GnRHa）抑制性腺发育和激素分泌，从而延缓青春期的发育。<mark>青春期阻滞治疗旨在暂停指派性别的第二性征发展，缓解性别焦虑，并为跨性别青少年提供探索性别身份的时间</mark>。

青春期阻滞治疗总体安全性较好，可抑制性激素分泌，停止第二性征的进一步发育，并使已初步发育的部分第二性征发生部分退化。若治疗在青春期后期开始，部分变化可能继续保留。在符合适应证并经专业评估的情况下，该治疗属于可选医疗方案。部分人可能出现过敏、皮疹、头痛、潮红、短暂性激素波动和骨密度较同龄人偏低等反应，需要定期监测身高、骨密度和生长发育。在部分地区，这一用途可能属于超说明书用药，但这不否定其医疗必要性；具体方案应由本人、法定监护人和专业医疗团队共同决定，且该治疗不能替代必要的心理或精神科治疗。

> [!NOTE] 部分青春期阻滞治疗资源参考
>
> * 北京大学第三医院易性症综合 / 激素治疗门诊
> * 复旦大学附属儿科医院跨性别 MDT 门诊
> * 暨南大学附属第一医院跨性别序列医疗 / 内分泌治疗门诊

> [!NOTE] 进行青春期阻滞治疗的基本条件
>
> * 经精神科医师评估，获取跨性别身份相关诊断
> * 对自身情况具有清晰的认知，有明确的进行青春期阻滞治疗的需求
> * 未患有可能影响自我认知与知情同意判断的精神障碍，或原有精神障碍已得到有效控制
> * 性发育达到 Tanner 2 期（青春期早期，出现初步的第二性征发育）或以上
> * 需由法定监护人同意
> * 已讨论生育影响及生育力保存选项，并能进行规律的医疗监测和随诊

## 性别肯定激素治疗

性别肯定激素治疗包括女性化激素治疗和男性化激素治疗，分别适用于女性倾向跨性别者和男性倾向跨性别者。<mark>性别肯定激素治疗旨在暂停相应指派性别的第二性征发展，促进认同性别的第二性征发育。对于完成性腺切除等手术的跨性别者，激素治疗则用于维持对应性别的激素水平范围</mark>。激素治疗方案因人而异，<mark>具体方案应根据实际情况和个人需求制定</mark>。

> [!NOTE] 部分性别肯定激素治疗资源参考
>
> * 北京大学第三医院易性症综合 / 激素治疗门诊
> * 上海交通大学医学院附属第九人民医院性别医学专科门诊（南部院区）
> * 暨南大学附属第一医院跨性别序列医疗 / 内分泌治疗门诊

> [!NOTE] 进行性别肯定激素治疗的基本条件
>
> * 经精神科医师评估，获取跨性别身份相关诊断
> * 对自身情况具有清晰的认知，有明确的进行激素治疗的需求
> * 未患有可能影响自我认知与知情同意判断的精神障碍，或原有精神障碍已得到有效控制
> * 治疗前检查无激素治疗相关禁忌症
> * 需由法定监护人同意
> * 已讨论生育影响及生育力保存选项，并能规律进行医疗监测和随诊

> [!NOTE] 应用性别肯定激素治疗的前置检查项目
>
> * 血常规
> * 肝肾功能
> * 电解质
> * 凝血功能
> * 血糖血脂
> * 性激素 6 项（泌乳素、卵泡刺激素、黄体生成素、雌二醇、睾酮、孕酮）
> * 乳腺超声
> * 骨密度

不同医院的前置检查和复查安排可能并不相同。<mark>激素治疗第一年通常每 3 个月复查一次，或在剂量调整时复查；进入稳定方案后，通常每年复查 1～2 次</mark>。复查项目、泌乳素是否监测以及是否需要全面体检，应结合具体治疗方案、医院要求和个体情况确定。下文所示的激素治疗方案、效果及风险参考跨性别和多元性别人群健康照护指南（第八版）[^2]，用于帮助了解常见方案和监测方向，不构成处方或用药建议。实际药物、剂量和监测频率需要根据个体情况动态调整，使性激素水平处于适合个体的范围内。

> [!NOTE] 性别肯定激素治疗的一般方案
>
> * 女性化激素治疗（使用如醋酸环丙孕酮等抗雄激素和雌二醇等雌激素）
> * 男性化激素治疗（使用如睾酮等雄激素）

> [!TIP] 女性化激素治疗的用药方案（以雌激素为基础的方案）<sup>*</sup>
>
> 雌激素：
> * 口服 / 含服药物：2～6 毫克（mg）/ 每天
> * 经皮吸收药物：0.025～0.2 毫克（mg）/ 每天
> * 凝胶类药物：每日涂抹<sup>‡</sup>
> * 肌肉注射药物：2～10 毫克（mg）/ 每周、5～30 毫克（mg）/ 每 2 周
>
> 抗雄激素：
> * 螺内酯：100～300 毫克（mg）/ 每天
> * 醋酸环丙孕酮：10 毫克（mg）/ 每天
>
> *. 目前无充分证据表明，使用黄体酮等孕激素能促进身体女性化，或其潜在获益超过潜在风险。醋酸环丙孕酮虽同属孕激素，但在激素治疗中主要作为抗雄激素使用，两者作用机制不同。
>
> ‡. 用量因药物剂型和浓度而异

> [!TIP] 男性化激素治疗的用药方案（以雄激素为基础的方案）
>
> 雄激素：
> * 睾酮凝胶：50～100 毫克（mg）/ 每天
> * 庚酸睾酮 / 环戊丙酸睾酮：每周肌肉或皮下注射 50～100 毫克（mg）、每两周肌肉注射 100～200 毫克（mg）
> * 十一酸睾酮：每 12 周肌肉注射 1000 毫克（mg）、每 10 周肌肉注射 750 毫克（mg）

> [!TIP] 性别肯定激素治疗的激素监测参考
>
> 女性倾向跨性别者：
> * 血清雌二醇水平应在 100～200 皮克（pg）/ 毫升（mL）范围内
> * 血清睾酮水平应低于 50 纳克（ng）/ 分升（dL）
>
> 男性倾向跨性别者：
> * 血清睾酮水平应在 400～700 纳克（ng）/ 分升（dL）范围内

## 性别肯定手术

性别肯定手术包括适用于女性倾向跨性别者和男性倾向跨性别者的手术项目。<mark>性别肯定手术旨在减少指派性别的部分性征，促进认同性别的性征表达</mark>。

> [!NOTE] 部分性别肯定手术医疗资源参考
>
> * 中国医学科学院整形外科医院
> * 北京大学第三医院整形外科
> * 上海交通大学医学院附属第九人民医院整复外科
> * 中国人民解放军第四一一医院整形外科

> [!NOTE] 进行性别肯定手术的基本条件
>
> * 经精神科医师评估，获取跨性别身份相关诊断
> * 对自身情况具有清晰的认知，有明确的进行手术的需求
> * 年满 18 周岁
> * 术前检查无手术相关禁忌症
> * 已讨论生育影响及生育力保存选项
> * 手术对象本人提供要求手术并经本人签字的书面报告<sup>*</sup>
> * 手术对象本人提供已告知直系亲属进行手术的证明<sup>*</sup>
> * 需由当地公安部门出具手术对象的《无在案犯罪记录证明》<sup>*</sup>
>
> *代表仅第一性征相关手术适用，院方可能会要求对材料进行公证。

> [!NOTE] 女性倾向性别肯定手术的一般项目
>
> * 第一性征女性化手术
> * 面部女性化手术
> * 喉结缩小手术

> [!NOTE] 男性倾向性别肯定手术的一般项目
>
> * 第一性征男性化手术
> * 面部男性化手术
> * 胸部切除 / 缩小手术

## 嗓音女性化训练

嗓音女性化训练是一种通过训练实现嗓音改变的手段，适用于女性倾向跨性别者。<mark>嗓音训练旨在通过系统训练调整嗓音，使其更符合认同性别</mark>。

嗓音训练通常根据个体的声音条件、沟通需求和目标制定，不存在适用于所有人的统一基频标准，训练内容可能涉及音高、音域、音色与共鸣、响度及发声方式等，具体重点因人而异。在适合的情况下，嗓音训练是优先考虑的干预方式之一，其风险相对低于手术，也便于逐步调整。

> [!NOTE] 部分嗓音女性化训练医疗资源参考
>
> * 首都医科大学附属北京友谊医院耳鼻喉科门诊
> * 上海市长宁区精神卫生中心嗓音言语专病门诊

> [!NOTE] 嗓音女性化训练的主要方式
>
> * 基于康复医学的练习方式
> * 基于声乐理论的练习方式

与基于声乐理论的练习相比，基于康复医学的嗓音训练对声带和声道长度的生理条件要求较低，主要通过改善受训者发声的声学与感知差异（如基频、音色）实现嗓音女性化。需要注意的是，嗓音训练效果因训练方式和个体生理条件不同而异。

> [!NOTE] 嗓音女性化训练的主要步骤
>
> * 通过调整声道和气息将基频提升至超过 175 Hz
> * 通过调整嘴形、呼吸等方式对音色进行修饰
> * 通过对话等练习保证自发言语状态下的嗓音稳定性

## 嗓音女性化手术

嗓音女性化手术是一种通过手术实现嗓音改变的手段，适用于女性倾向跨性别者。<mark>嗓音手术旨在通过手术调整嗓音，使其更符合认同性别</mark>。

嗓音手术存在一定风险，最终效果受术式、个体条件及术后照护影响，且存在一定不确定性，术后通常仍需配合训练。

>
> * 首都医科大学附属北京友谊医院耳鼻喉科门诊
> * 南京同仁医院嗓音中心

## 心理健康与长期照护

性别不一致本身不是精神障碍，但歧视、排斥和医疗障碍可能增加焦虑、抑郁及自伤风险。心理支持应贯穿医疗照护过程，评估时也需要区分性别不一致和同时存在的心理健康问题。心理治疗的目标不是改变一个人的性别认同，而是帮助其应对情绪、压力和现实处境；以改变性别认同或表达为目的的扭转治疗无效且有害，不能与支持性心理治疗混为一谈。

激素治疗和部分手术可能影响生育能力。治疗前可根据个人需求，结合身体条件、医疗资源和当地政策，讨论是否进行生育力保存。

长期健康照护应结合身体结构、激素使用和既往手术情况，关注泌尿及妇科健康、心血管、骨密度、内分泌与代谢、皮肤健康、性传播感染和肿瘤筛查。
