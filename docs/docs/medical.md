# 医疗照护

## 性别肯定医疗概述

性别肯定医疗以个人需求、知情同意和持续评估为基础，通常包括内分泌治疗、手术、嗓音训练等，并结合心理支持及长期健康管理。不同项目可以单独或组合采用，选择接受哪些项目取决于个人需求。性别肯定医疗的目的是缓解性别焦虑、提升自我接纳和心理健康水平，对有医疗需求者的身心健康具有重要意义。心理支持通常贯穿照护全过程。

## 医疗评估与诊断

在性别肯定医疗中，相关诊断与评估用于了解个人的性别相关体验和医疗需求，为后续照护提供依据。精神科评估还关注心理健康状况，区分性别相关困扰与同时存在的其他心理健康问题。评估通常以临床沟通为基础，了解既往经历、当前状况和医疗需求，必要时可结合心理评估或其他检查，以进一步了解相关健康状况。

> [!NOTE] 不同诊断分类标准中的相关名称
>
> |诊断名称|分类标准|
> |:-:|:-:|
> |易性症|《疾病和有关健康问题的国际统计分类》第十次修订本（ICD-10）|
> |性身份障碍|《精神障碍诊断与统计手册（第四版）》（DSM-IV）|
> |性别不安|《精神障碍诊断与统计手册（第五版）》（DSM-5）|
> |性别不一致|《国际疾病分类第十一次修订本》（ICD-11）|

上述诊断名称来自不同版本的分类标准，反映了医学对性别相关困扰和照护需求的不同认识。需要注意的是，跨性别本身并不是精神障碍，精神科评估所关注的是相关困扰、心理健康状况及医疗需求。世界卫生组织在《国际疾病分类第十一次修订本》（ICD-11）中，以“性别不一致”替代了“易性症”等旧诊断分类，并将相关条目从“精神和行为障碍”章节移入“性健康相关情况”章节[^1]。这一变化有助于减少病理化与污名。

## 青春期阻滞治疗

青春期阻滞治疗通常使用促性腺激素释放激素类似物（GnRHa），抑制性激素分泌，延缓青春期的第二性征发展。这类治疗用于青春期已经开始、出现初步第二性征的青少年。治疗的目的是暂停指派性别的第二性征发展，为青少年提供探索性别身份的时间。

治疗可以暂停第二性征的进一步发展，部分初期变化可能出现一定程度的退化。青春期后期已经形成的部分性征可能继续保留，治疗不能逆转所有青春期变化。

部分人可能出现头痛、潮红等不良反应，现有研究对治疗的长期获益和风险仍有不确定性。这一用途在部分地区属于超说明书用药，即未列入药品说明书批准的用途。治疗的医疗必要性与青少年的具体需求和临床评估有关。心理支持或精神科治疗可以根据个人的心理健康需求，与青春期阻滞治疗结合开展。

## 性别肯定激素治疗

性别肯定激素治疗包括女性化激素治疗和男性化激素治疗，分别适用于女性倾向跨性别者和男性倾向跨性别者。治疗的目的是抑制部分指派性别的第二性征发展，促进认同性别的第二性征发育。对于接受性腺切除手术的个体，激素治疗还用于补充性激素、维护长期健康。不同个体的治疗目标和预期变化有所不同。

> [!NOTE] 女性化与男性化激素治疗
>
> * 女性化激素治疗：雌激素（如雌二醇）及抗雄激素（如醋酸环丙孕酮）。
> * 男性化激素治疗：雄激素（如睾酮）。

目前尚无充分研究支持黄体酮等孕激素能够促进身体女性化。醋酸环丙孕酮虽同属孕激素，但在女性化激素治疗中主要用作抗雄激素。

下列治疗效果和相关风险参考《跨性别和多元性别人群健康照护指南（第八版）》[^2]整理。治疗效果出现的时间和程度因人而异，相关风险也受具体治疗方案和个人健康状况影响。

## 性别肯定手术

性别肯定手术通过改变部分身体性征满足个人的医疗需求，包括适用于女性倾向跨性别者和男性倾向跨性别者的手术项目。不同手术项目可以单独或组合采用，以适应不同的身体改变需求。这些改变有助于改善生活质量。

性别肯定手术的效果、风险和恢复过程因手术项目、术式及身体条件而异。术后随访用于评估恢复情况与手术效果，并及时发现和处理并发症，部分手术涉及长期随访。

> [!NOTE] 女性倾向性别肯定手术的一般项目
>
> * 第一性征女性化手术
> * 胸部 / 乳房手术
> * 面部女性化手术
> * 喉结缩小手术

> [!NOTE] 男性倾向性别肯定手术的一般项目
>
> * 第一性征男性化手术
> * 胸部切除 / 缩小手术
> * 面部男性化手术

## 嗓音治疗

嗓音治疗包括嗓音训练和嗓音手术，用于改变嗓音特征。嗓音训练通常可以单独开展，嗓音手术则通常需要配合嗓音训练。不同个体对嗓音的需求有所不同，治疗目标通常结合个人的声音条件、沟通需求和期望制定。

嗓音训练通过调整发声方式，改变音高、音色、共鸣等特征。嗓音的性别特征并不只取决于音高，也不存在适用于所有人的统一基频标准。训练效果因训练方式和个体条件而异。

嗓音女性化手术通常适用于女性倾向跨性别者，通过改变声带结构等方式提高音高。手术主要改变音高，结合嗓音训练可以进一步调整音色、共鸣及发声方式。手术效果和风险因术式、个体条件及术后照护而异。

## 心理支持与长期健康

歧视、排斥和医疗障碍可能增加焦虑、抑郁及自伤风险。心理治疗以尊重个人的性别认同为基础，目的是帮助个人应对情绪、压力和现实处境。以改变性别认同或表达为目的的扭转治疗无效且有害。

激素治疗及部分涉及性腺或生殖器官的手术可能影响生育能力，影响的程度和持续时间因治疗项目而异。生育力保存用于保留未来生育的可能性，通常在可能影响生育能力的治疗前进行。相关需求因个人的生育意愿和身体条件而异。

长期健康照护既关注一般健康需求，也关注激素治疗和手术的长期影响。相关健康评估和疾病预防可以结合身体结构、激素使用和既往手术情况，具体内容因个人身体状况而异。
