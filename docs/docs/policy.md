# 政策法规

## 证件性别信息变更

根据《户口居民身份证管理工作规范（试行）》（公通字〔2021〕12 号）第五十四条规定，公民的性别登记可以依照相关规定变更[^1]。

性别登记变更后，公民身份号码会一并变更，原居民身份证和原公民身份号码会被注销，公安机关会更新户口登记信息并换发新的居民身份证和居民户口簿。需要注意的是，公安机关以外的机构通常不会同步更新实名登记信息。

## 学籍性别信息变更

根据《教育部关于印发〈高等学校学生学籍学历电子注册办法〉的通知》（教学〔2014〕11 号）规定，学生在校期间变更身份信息后，相关学籍信息可以经审核变更[^2]。该办法主要适用于高等教育阶段；普通高中及以下阶段的学籍信息变更依据和做法可能不同。

该办法第十九条规定，学历注册并提供网上查询后，学校不得变更证书内容及注册信息，不再受理学生信息变更事宜。因此，学籍信息变更通常需在学历注册前完成。注册信息确有错误的，则适用另行审核更正的规定。这类更正针对原有注册信息的错误，与性别登记变更后产生的新旧信息差异不同。

## 适用于学历信息与身份信息不一致

毕业后如变更性别信息，学历证书和学历注册信息会与现身份信息不一致。以下内容整理了一种可供参考的变通方式。

> [!WARNING] 根据《普通高等学校学生管理规定》（教育部令第 41 号）第三十八条规定，学历证书和学位证书遗失或者损坏，经本人申请、学校核实后，学校应当出具相应的证明书。该证明书与原证书具有同等效力。

在此基础上，可以向毕业院校申请补办“现身份信息的学历证明书”；能否出具及具体做法，需以毕业院校和相关教育管理部门要求为准[^3]。

需要注意的是，如毕业院校出具与现身份信息对应的学历证明书，该证明书用于证明学历与现身份信息的对应关系，并不意味着学历注册信息会同步更新。
