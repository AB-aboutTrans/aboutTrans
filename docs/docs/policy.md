# 跨性别相关政策法规

## 适用于证件信息变更

根据《户口居民身份证管理工作规范（试行）》（公通字〔2021〕12 号），在完成性别肯定手术后，可以向<mark>户口所在地公安部门</mark>提交相关医疗证明，申请性别变更。

> [!NOTE] 申请证件性别变更所需的材料
>
> * 国内三级医院出具的性别鉴定证明或者具备资格的司法鉴定机构出具的证明<sup>*</sup>
> * 居民身份证和居民户口簿原件
> * 本人申请书
>
> *. 部分地区可能要求对医疗证明进行公证，具体以当地公安机关要求为准。

办理性别变更后，公民身份号码会一并变更，原居民身份证和原公民身份号码会被注销，公安机关会更新户口登记信息并换发新的居民身份证和居民户口簿。需要注意的是，银行、通信、出入境以及其他公安以外机构的实名登记信息不会同步更新，身份信息变更相关证明通常需要妥善保存，以便后续更新相关信息。

## 适用于学籍信息变更

根据《教育部关于印发〈高等学校学生学籍学历电子注册办法〉的通知》（教学〔2014〕11 号）规定，学生在校期间完成居民身份证性别变更后，可以向<mark>学校学籍管理部门</mark>申请变更学籍信息。

> [!CAUTION] 根据《高等学校学生学籍学历电子注册办法》第十九条，“学历注册并提供网上查询后，学校不得变更证书内容及注册信息，不再受理学生信息变更事宜。”因此，学籍信息变更通常需在学历注册前完成。

> [!NOTE] 申请学籍性别变更所需的材料
>
> * 居民身份证及居民户口簿变更前后的复印件
> * 公安部门出具的居民身份证性别变更证明
> * 公安部门出具的公民身份号码变更证明
> * 公安部门出具的常住人口信息登记表
> * 本人申请书
> * 同一人证明
>
> 注：不同学校所需材料可能有所不同，具体要求需联系校方核实。

如果学校完成学籍信息变更，学信网账号及身份信息的匹配方式需以学信网和校方学籍管理部门要求为准，部分情况下可能需要重新注册账号。

## 适用于学历信息不符

毕业后修改性别信息后，学历证书和学历注册信息会与现身份信息不一致。以下内容整理了一种可供参考的处理方式。

> [!WARNING] 根据《普通高等学校学生管理规定》（教育部令第 41 号）第三十八条，学历证书和学位证书遗失或者损坏的，经本人申请、学校核实后，学校应当出具相应证明书。该证明书与原证书具有同等效力。对于学历信息不一致的情况，可以向毕业院校咨询或申请出具相应学历证明书；具体做法需以毕业院校及相关教育管理部门要求为准。

需要注意的是，学历证明书用于证明个人学历及其与现身份信息的对应关系，并不意味着相关学历信息会同步更新。具体处理方式以毕业院校及相关教育管理部门的要求为准。
