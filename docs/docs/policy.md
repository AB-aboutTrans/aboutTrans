# 政策法规

## 证件性别信息变更

根据《户口居民身份证管理工作规范（试行）》（公通字〔2021〕12 号）第五十四条规定，公民的性别登记可以依照相关规定变更，医疗或司法鉴定机构出具的性别鉴定证明是该规范中的变更依据[^1]。各地的规定以这一规范为依据，执行要求可能有所不同。

性别登记变更后，公安机关会重新分配公民身份号码，并换发新的居民身份证和居民户口簿，原居民身份证会被收回并作废[^2]。需要注意的是，公安机关以外的机构通常不会同步更新实名登记信息。

## 学籍性别信息变更

根据《高等学校学生学籍学历电子注册办法》（教学〔2014〕11 号）规定，学生在校期间变更身份信息后，可以通过相应的证明材料变更学籍中的身份信息，相关变更需经学校或省级教育行政部门审核确认。学信网保留变更前的信息[^3]。该办法适用于高等学历教育，普通高中及以下阶段不属于其适用范围。

该办法第十九条规定，学历注册并提供网上查询后，学校不得变更证书内容及注册信息，也不再受理学生信息变更事宜。因此，学籍信息变更通常需在学历注册前完成。

## 学历信息与身份信息的差异

毕业后变更性别信息，学历证书和学历注册信息会与现身份信息不一致。学历证书、学历证明书等材料与身份信息变更证明相结合，可以作为衔接新旧身份信息的变通方式。

根据《普通高等学校学生管理规定》（教育部令第 41 号）第三十八条规定，学历证书和学位证书遗失或者损坏，经学校核实后出具的相应证明书与原证书具有同等效力[^4]。

在学历核验中，身份信息变更证明可以说明姓名、公民身份号码等信息的变更情况。学历注册信息仍受《高等学校学生学籍学历电子注册办法》第十九条的变更限制，出具证明书并不意味着注册信息同步更新。
