# 关于我们

## 跨越偏见、拥抱多元

aboutTrans 是由社群共建的跨性别与多元性别知识平台。我们致力于向公众介绍以跨性别为主、涵盖多元性别议题的知识，帮助更多人了解并支持跨性别与多元性别群体。

> [!IMPORTANT] 内容须知
> aboutTrans 是一个专注于跨性别与多元性别知识科普的公益性站点，无论是社群伙伴还是盟友朋友，都可以在此获取有用的信息。内容编写参考了潘柏林的《走出性别困境》[^1]等资料，并结合社群建议。如发现内容错误，欢迎指出；也欢迎参与内容编写。感谢所有为跨性别与多元性别群体相关事业付出努力的社群工作者。

> [!IMPORTANT] 免责声明
> aboutTrans 致力于为公众提供相对客观的信息服务，但我们无法保证内容的绝对准确性，使用者须自行对依赖本站信息作出的决定及其后果负责。本站的概念术语内容基于现有学术研究及社群共识整理；医疗相关内容不构成专业医疗建议，具体医疗方案的实施应在正规医疗机构的指导下进行；政策相关内容可能因地而异并随时更新，请以官方发布的最新信息为准；所收录的机构、引用的案例及第三方链接仅供参考，不代表本站观点或立场。
